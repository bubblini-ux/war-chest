# War Chest

Working knowledge vault and project blueprint for a rare World War II firearms and militaria collector client.

Start at [`Home.md`](./Home.md) when browsing in Obsidian or Markdown.

## Purpose

This repository holds the discovery, compliance, inventory cataloging, operations, marketing, and website specifications needed to scope, build, and launch the client's platform safely and legally.

> **Important:** Per [`Compliance/Confidentiality Standard.md`](./Compliance/Confidentiality%20Standard.md), this repository is **Internal / Confidential** and must remain in a **private** Git repository. Never commit **Restricted** data (full serial numbers, firearm transfer records, registration papers, licence copies, identity documents, passwords, keys, or storage locations).
