# Accessibility Standard

Back to [[Home]]. Target: Web Content Accessibility Guidelines 2.2, level AA. Every page must work with a screen reader and a keyboard alone.

## Pages

1. Use one main heading and a logical heading order.
2. Give every page a unique title and landmarks.
3. Include a link to skip to the main content.
4. Keep the focus visible and the tab order logical.
5. Respect the visitor's reduced motion setting.

## Item pages and images

1. Write alt text that gives real detail. For example: "Left side of the receiver showing the maker's stamp and 1943 date."
2. Give photo galleries clear labels and full keyboard control.
3. Don't convey legal status or availability by color alone.
4. Provide text for anything shown only in an image.

## Filters and forms

1. Label every form field.
2. Link errors to their fields and describe how to fix them.
3. Announce updated result counts to screen readers when a filter changes.
4. Don't use visual puzzles to block spam.

## Testing

1. Run an automated check on each page template.
2. Test by hand using a screen reader and keyboard.
3. Treat accessibility bugs as launch blockers.
