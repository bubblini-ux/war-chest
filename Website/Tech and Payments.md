# Tech and Payments

Back to [[Home]]. Check every vendor against [[Platform Restrictions]] before choosing.

## Recommended direction

A static site generated from a structured catalog, with a simple content editor and an enquiry form. It's fast, cheap to run, secure, and easy to move if a host drops the customer.

## Requirements

1. Own the domain and DNS in the customer's name.
2. Use a host with written acceptance of the business.
3. Keep a copy of the site that can be redeployed elsewhere quickly.
4. Keep public catalog data separate from private records.
5. Send enquiry forms through a provider that permits this business.

## Payments

1. Start with invoices or a bank wire after the customer approves each sale.
2. Add a firearms-friendly merchant account only if the customer wants online payment.
3. Write down each processor's approval and terms.

## Security and privacy

1. Buyer enquiries and licence copies are sensitive. Collect only what's needed.
2. Don't store licences or identity documents on the website.
3. Use spam protection on forms that also works with a screen reader, avoiding visual puzzles.
4. Turn on two-factor login for every admin account.
5. Publish a privacy policy that matches what the site really does.
